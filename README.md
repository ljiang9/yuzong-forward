# 余总转发文案 —— 社媒运营翻车模拟器

致敬 2026-10-04 热梗：某大厂社媒运营转发时，把后台备注「余总转发文案」原样发出，
空降热搜。当事人随后幽默回应，全网玩梗但无恶意。本项目纯属虚构、善意玩梗，
如有雷同，说明你也是运营。

## 玩法

你是一名大厂社媒运营。屏幕上是一条待转发的微博，正文里混入了内部备注
（`[余总转发文案]`、`[老板还没审]`、`[删括号内]`、`[配图还没P]`……）。
倒计时内输入编号删掉**所有备注**，再输入「发」发送。

- 输入 `1 3`：删除 1 号、3 号条目
- 输入 `发`：发送微博
- 输入 `q`：退出

注意：有些括号是正文内容（如 `[投票]`、`[链接]`），删了它们 = 删错正文，
直接翻车。难度递增：备注越来越多、诱饵越来越多、时间越来越短。

### 翻车结算（按翻车程度）

| 翻车 | 剧情 |
|---|---|
| 小翻车·评论区玩梗 | 1条备注泄露，网友：备注比正文好看 |
| 中翻车·登顶热搜 | 2条备注泄露，运营连夜删博重发 |
| 大翻车·余总亲自下场 | 3条备注泄露，余总幽默回应，全网狂欢 |
| 史诗翻车·删了正文 | 误删正文括号，粉丝排队要链接 |
| 删错翻车 | 编号不对，删掉了正文的一部分 |
| 超时翻车 | 倒计时结束，备注原样发出 |
| 手滑翻车 | 无效指令太多，手机差点飞出去 |

成功发出则得分（剩余时间越多分越高），进入下一轮，直到翻车为止。

## 运行

```bash
python3 -m yuzong_forward            # 交互模式（需要终端）
python3 -m yuzong_forward --auto --games 10 --seed 42   # AI 运营自动玩 10 局
python3 -m yuzong_forward --auto --games 20 --seed 7 --skill 0.6  # 菜鸟运营
```

`--seed` 保证可复现；`--skill 0~1` 调整 AI 运营靠谱程度。

## 真实验证记录

- `python3 -m py_compile yuzong_forward.py __main__.py`：通过
- 单元测试（7 项）：草稿备注/诱饵数量、编号渲染、删备注/误删/越界/重复删、
  指令解析、翻车分级、AI 同种子可复现、自动 10 局正常结束：全部通过
- `--auto --games 10 --seed 42`：10 局完成，翻车 7 局、翻车率 70%（AI 会误判诱饵/漏备注/手滑）
- 非 tty 运行交互模式：中文提示，exit 2

## 已知局限（诚实版）

- 倒计时输入用 `select` 实现，仅 Unix 终端有效；Windows 需自行适配
- AI 运营是简单的概率模型，不是真人手速模拟
- 文案为虚构池，玩多局会眼熟；无图形界面、网络对战
- Python 3.10+，纯标准库
